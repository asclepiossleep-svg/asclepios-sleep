# Asclepios Business Launch Readiness Map V0.1

Status: ACTIVE / OWNER-VISIBLE
Launch principle: product stock should arrive into a business system that is already ready to sell, explain, take payment, fulfil, support and measure.

## Launch objective
When physical stock is available, Asclepios should not begin preparing to sell. The commercial framework should already be operating so stock can be listed and sold with minimal additional work.

## Priority order
### P0 — Must exist before stock is launchable
1. Public company / brand website shell
2. Product catalogue + product detail pages
3. Checkout / payment path
4. Order confirmation + basic order-status path
5. Shipping / fulfilment method and operating SOP
6. Returns / refund / customer-support path
7. Product claims / safety / instructions consistency
8. Inventory / stock-state handling

### P1 — Must be prepared in parallel before launch
1. Product education content
2. Short-form marketing scripts / videos
3. Long-form explainer content
4. FAQ / CS knowledge base
5. CRM / customer records / campaign capture
6. Sales / conversion / order / stock KPI reporting
7. QR / entitlement / app activation path where applicable

### P2 — Core IP continues in parallel but does not block commerce shell
1. Sleep Intelligence V1
2. Adaptive assessment
3. Behaviour / adherence engine
4. Programme optimisation
5. Deeper app personalisation
